
# NamiPay Terminal API for iOS

**TerminalAPIKit** The Nami Payment iOS SDK enables seamless integration of the Nami Payment [Terminal](https://docs.namipay.com.sa/docs/new-ios-ecr-sdk) with your iOS ECR application. It includes the required models for creating Terminal API requests and provides built-in security for local Terminal API communications.


## Install TerminalAPIKit
TerminalAPIKit for iOS is available through [Swift Package Manager](https://swift.org/package-manager/). 

To install the kit:

1. In your Xcode project, go to **File** > **Swift Packages** > **Add Package Dependency**.
1. Enter `https://github.com/Nami-Development/nami-ios-sdk` as the repository URL.


For detailed instructions see [Adding Package Dependencies to Your App](https://developer.apple.com/documentation/xcode/adding_package_dependencies_to_your_app).
